DealLens 4.0.1 — fix "Sheet sync failed: error:1E08010C:DECODER routines::unsupported"

WHAT WAS WRONG
That error means Node couldn't read GOOGLE_PRIVATE_KEY. I reproduced it: the key only worked if it was
pasted in exactly one of two forms. Surrounding quotes, a trailing comma, doubled \\n, spaces instead of
line breaks, Windows line endings, or pasting the whole JSON file all gave this same error.

WHAT CHANGED
- lib/google.ts: the key is cleaned up and rebuilt before use, so all of those paste forms now work
  (14 forms tested). If the key is truly broken, the sync error now says so in plain words.
- Optional: you can paste the whole downloaded JSON key file into ONE variable, GOOGLE_SERVICE_ACCOUNT_JSON,
  instead of GOOGLE_SERVICE_ACCOUNT_EMAIL + GOOGLE_PRIVATE_KEY. You don't need to change anything if you
  keep the two you already added.
- tests/key.test.mts (new), tests/google.test.mts, package.json (test script, version), .env.example.
