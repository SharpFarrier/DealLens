DealLens 5.1: every listing checked automatically each morning

What changes
- A GitHub job runs every morning at 6:45 am India time: it syncs the sheet, then checks every
  Amazon and Flipkart listing in chunks until all are done (about 20-30 minutes), then retries
  anything that couldn't be checked, once. Nobody needs to press Check all or keep a tab open.
- Vercel's daily 9:00 am check stays as a backup; once the morning job has finished it has nothing
  left to do and uses no Scrapingdog credits.
- Fixed: the 30-day bars could miss some days once there were more than 1,000 history rows.
- No database change this time.

STEP 1 - Terminal:

cd ~/DealLens
git pull
rm -rf /tmp/deallens-51 && unzip -q ~/Downloads/DealLens_v5.1.zip -d /tmp/deallens-51
rsync -a /tmp/deallens-51/deallens-v5.1/ ~/DealLens/
git status --short
git add -A
git commit -m "DealLens 5.1: morning check for every listing"
git push

STEP 2 - GitHub secret (one time):
  github.com/SharpFarrier/DealLens > Settings > Secrets and variables > Actions > New repository secret
  Name: CRON_SECRET
  Value: the same CRON_SECRET that is in Vercel (Vercel > deal-lens > Settings > Environment Variables)

STEP 3 - In DealLens: avatar (top right) > Settings > switch on "Daily Live status check".

STEP 4 - Try it now instead of waiting for tomorrow:
  github.com/SharpFarrier/DealLens > Actions > Morning Live status check > Run workflow.
  Each line in the log shows how many were checked and how many are left.
